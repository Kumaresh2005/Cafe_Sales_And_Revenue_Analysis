# Cafe_Sales_And_Revenue_Analysis
![Dashboard Screenshot](https://github.com/Kumaresh2005/Cafe_Sales_And_Revenue_Analysis/blob/main/Screenshot%202026-05-10%20182758.png?raw=true)
Interactive Cafe Sales &amp; Revenue Dashboard built in Excel using Pivot Tables, Charts, Slicers, and KPI Cards. This dashboard provides insights into revenue trends, product performance, payment methods, purchase types, and city-wise sales analysis with dynamic filtering and professional visualization.
